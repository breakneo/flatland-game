# 《平面国》小游戏任务契约 (TASK_SPEC)

## 一、 项目愿景与最狭窄切入点 (Narrowest Wedge)
- **核心定位**：一款融合“第一人称维度认知受限”与“全知 3D 俯瞰反差”的极简空间哲学解谜小游戏。
- **最狭窄切入点**：通过**“双视窗联动（主观受限视角 vs 全知三维俯瞰）”**，在 3~5 个精炼关卡中完整重现从 1D（线）到 2D（面）再到 3D（体）的升维顿悟，并在通关后以 0D（点）的荒诞唯我主义彩蛋升华原著哲学。

---

## 二、 统一领域语言 (Ubiquitous Language)
1. **主观视窗 (Subjective Viewport)**：
   - 当前维度生物的第一人称真实视野。
   - 1D 视野：单一亮斑/点（前后视锥为 0 维点，仅能看到前方障碍物的颜色与距离衰减）。
   - 2D 视野：带迷雾深浅的线段地平线（原著“雾中辨角法”：近处明亮锐利，远处灰暗模糊）。
   - 3D 视野：经典 3D 第一人称透视。
2. **全知视窗 (Omniscient 3D Viewport)**：
   - 现代三维上帝俯瞰视角，常驻屏幕一隅（分屏），将玩家的主观困境直观还原在三维空间中，形成强烈的“认知荒谬感”。
3. **升维跃迁 (Dimensional Ascension)**：
   - 突破当前维度自由度限制的核心通关机制（1D 解锁左右轴绕行；2D 解锁高度轴翻越；3D 终结）。
4. **终局彩蛋：点之国 (Pointland Easter Egg)**：
   - 零维空间，玩家无法移动，只有无限膨胀的自我意识，致敬原著第 13 章。

---

## 三、 显式非目标 (Explicit Non-Goals)
- ❌ **不做复杂的 4D 真实代数模拟**：防止包体膨胀与性能崩溃，聚焦于 0D~3D 的认知反差。
- ❌ **不做冗长的纯文字剧情对白**：原著文本精炼为 1~2 句黑色幽默旁白，不拖慢解谜节奏。
- ❌ **首版坚决剔除外围冗余系统**：无好友社交、无聊天、无复杂装备数值养成，专注单局核心解谜。

---

## 四、 核心关卡架构与交互设计

### 1. 视口排布（移动端竖屏 9:16 或分屏）
- **上半屏：全知 3D 视窗（Omniscient View）**
  - 维多利亚时期复古铜版画/机械模型沙盘风。
  - 玩家看到自己作为一根线/一个正方形在沙盘迷宫中的真实位置，但无法直接操控高维移动。
- **下半屏：主观视窗（Subjective View）**
  - **1D 关卡**：屏幕中央仅有一条光纤般的色块点。只能左右按键（其实是前进/后退）。前方是敌人的“红色点”，由于 1D 无法绕行，看似绝对死路。
  - **2D 关卡**：玩家看到的是一条随转向而变换明暗、断裂的 1D 光带（带雾气深度衰减）。四周是封死的 2D 墙壁。
  - **3D 关卡**：完整 3D 自由空间，体验从低维飞升至广袤天地的豁然开朗。
- **通关彩蛋：0D 点国**：
  - 屏幕收缩为纯黑背景中一个极小的孤点。任何按键交互都会弹出点之国王的自我赞美：“啊，我的思想是何等完美！我就是一切！”

### 2. 美术风格与调性
- **维多利亚复古铜版画 + 牛皮纸手绘（Engraving & Parchment）**：
  - 带有古典数学仪器（黄铜罗盘、圆规、几何手稿）的边框与质感；
  - 几何图形带有拟人化的小眼睛或维多利亚绅士礼帽，兼具严肃哲学与黑色幽默。

## 五、 技术底线与商业化规范
- **引擎**：Cocos Creator 3.x + TypeScript。
- **包体限制**：首包 ≤ 4MB，材质贴图使用图集并压缩，音效与背景乐 CDN 远端加载。
- **商业化路径**：纯广告（IAA）合规免版号路径。仅在卡关时提供 1 个自愿激励视频“高维神谕（上帝视角透视提示）”。
- **性能红线**：iOS WebGL 内存 ≤ 800MB，全场景 DrawCall ≤ 50。

---

## 六、 验收标准 (Acceptance Criteria)
1. [ ] **双视窗同屏渲染**：主观视角与全知 3D 视角严格同步玩家位移与旋转。
2. [ ] **1D/2D 主观视野真实还原**：1D 仅呈现点前后感知，2D 呈现雾气深度线段，视觉逻辑符合原著几何学原理。
3. [ ] **升维机制闭环**：1D 升 2D、2D 升 3D 的突破动画与手感流畅，且能在 30~90 秒内完成单个谜题。
4. [ ] **0D 彩蛋完整闭环**：通关后自动解锁点国彩蛋，具备独立的荒谬人设与互动反馈。
