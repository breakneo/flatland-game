# 任务契约：序幕·直线国之梦与关卡调度器 (TASK_SPEC_LINELAND)

## 1. 业务目标与最狭窄闭环 (Narrowest Wedge)
将现有的单关 Demo 升级为支持多关卡流转的叙事解谜作品，首发交付：
- **核心关卡：序幕 · 直线国之梦 (Lineland)**
- **全局关卡协调器 (LevelCoordinator)**：负责 Level 0（序幕）与 Level 1（第一幕）的平滑流转与手稿结算。

## 2. 领域统一语言 (Ubiquitous Language)
- **单一直线世界 (Single-Line Universe)**：直线国所有居民被限制在同一条直线（$Y=0$）上，仅能沿着 X 轴前进或后退。
- **线之国王 (King of Lineland)**：位于正前方（$X > 0$）的端庄点状君王，发出威严自负的音阶。
- **暴躁邻人 (Aggressive Citizen)**：位于正后方（$X < 0$）的线段居民，逐步向前挤压。
- **前后死锁 (Bilateral Deadlock)**：当主角被前后夹击至间距低于 1.5 步长时触发，常规前后移动无法脱困。
- **向侧面一步 (Step Sideways)**：正方形绅士的维度顿悟觉醒——沿着 Y 轴脱离直线，在直线国居民视野中“凭空蒸发”，越过封锁进入梦境裂隙。
- **梦境手稿结算 (Manuscript Transition)**：通关后展示《直线国梦呓》手稿，点击直接进入“第一幕：石牢脱逃”。

## 3. 显式非目标 (Explicit Non-Goals)
- **非目标 1**：本轮不实现关卡 2（议会大清洗）和关卡 3（点之国）的具体玩法；
- **非目标 2**：不重构已有 Level 1 的 28 个核心测试用例，保证第一幕零回归风险；
- **非目标 3**：不引入重型路由库，保持纯 TypeScript 原生对象调度。

## 4. 验收标准 (Acceptance Criteria)
1. **纯逻辑 TDD 红绿灯**：新增 `LinelandGameController` 单元测试，覆盖单维移动、死锁判定、碰撞防御及侧移跃迁；
2. **双视窗渲染适配**：
   - 上屏呈现一维直线剖面（国王金光、邻人暗影、正方形端点）；
   - 下屏呈现纯正一维感知（视野中央单点光斑强弱变化）；
3. **闭环流转流程**：
   - 序幕死锁后右下角按钮点亮为【向侧面，而不是向前】；
   - 点击侧移后主角脱离直线越过国王，抵达梦境出口；
   - 弹出手稿并支持点击【进入第一幕·石牢脱逃】，无缝载入当前第一幕。
