# 任务契约：第二幕·议会大清洗与针形刺客 (TASK_SPEC_ACT2)

## 1. 业务目标与最狭窄切入点 (Narrowest Wedge)
实现《平面国》四幕完整体系中的核心第二幕：
- **关卡标识**：`GameLevelId.SPACELAND_PURGE`（第二幕 · 议会大清洗）
- **核心矛盾**：逃离石牢后，正方形绅士置身议会戒严街区，遭遇千年纪元禁令大清洗。
- **最狭窄切入点**：
  1. 纯逻辑控制器 `PurgeGameController`（多边形街区阻隔、针形刺客巡视、高维跳跃逃脱）；
  2. 原著世界观极度还原：引入原著最具威慑力的一维刺客——“针形女性 (Needle Assassin)”与“圆形大祭司 (Circle Priest)”；
  3. 关卡流转贯通：第一幕通关手稿无缝承接第二幕，第二幕通关后进入浩瀚三维虚空。

## 2. 领域统一语言 (Ubiquitous Language)
- **议会大清洗 (The Great Council Purge)**：最高圆形理事会签发特别禁令，严禁任何居民提及“第三维度”。
- **针形刺客 (Needle Assassin)**：原著中女性由于两端极细且无角，在迷雾中近乎隐形，迎面触碰具极高穿透致死率。
- **圆形祭司 (Circle Priest)**：最高统治阶层，具有无数微小边角近似完美的圆形躯体，具有大范围神圣光环感知区。
- **高维引渡法阵 (Spaceland Void Portal)**：球体导师降下的三维接引奇点，正方形飞跃进入后被彻底拉入三维空间。

## 3. 显式非目标 (Explicit Non-Goals)
- **非目标 1**：不开发过于复杂的 3D 物理引擎，复用当前高健壮性的 2D 碰撞多边形与 Z 轴升维逻辑；
- **非目标 2**：不破坏已有序幕与第一幕的 35 个核心单元测试；
- **非目标 3**：暂不展开第四幕（点之国），保持单步闭环。

## 4. 验收标准 (Acceptance Criteria)
1. **纯逻辑 TDD 红绿灯**：`tests/core/purge-controller.test.ts` 覆盖针形刺客避障、圆形祭司感知与高维通关判定；
2. **手稿起承转合**：第一幕通关后点击直接进入第二幕开场背景手稿，交代议会戒严与针形危险；
3. **实机无头 CDP 体检**：三幕往复切换 0 报错，实机落图清晰。
