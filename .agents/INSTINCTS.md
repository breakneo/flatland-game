# flatland-game 游戏开发实战经验与避坑直觉库 (INSTINCTS.md)

> 本文件记录 flatland-game 开发过程中提炼的实战经验，可自动同步回 Game-Studio 母库。

## 避坑记录

### 1. 等腰三角形几何朝向与射线求交
- **教训**：等腰三角形尖角（Apex）是其移动方向的“矛头”。在射线求交与多边形构建时，若顶点与底边顺序颠倒，会导致第一人称视线判定与实际巡逻兵朝向完全相反。
- **最佳实践**：以 Apex 为基准向正后方两侧偏移底边两点，并在构造函数中严格校验几何合法性。

### 2. Hit Stop 顿挫停顿解耦
- **教训**：打击停顿（0.08s 冻结帧）若直接 `return` 阻断全局 `update`，会导致胜利判定、UI 动效和状态机计时同步冻结，引发手感阻塞或终点不结算。
- **最佳实践**：Hit Stop 仅冻结位移物理步进，出口判定与状态更新独立于冻结标志之外。

### 3. Cocos 纯逻辑层零污染隔离
- **教训**：在核心算法中无意引入 Cocos 的 `Vec2` 或 `Node` 会破坏 TDD 循环，迫使测试依赖庞大的引擎 mock 环境。
- **最佳实践**：`assets/main/scripts/core/` 严格采用自研极简 `Point2D` 接口与原生数学函数，23 个用例仅 480ms 毫秒级通过。

### 4. 2D/3D 平面国世界观的“微薄厚度”视界
- **教训**：不能套用传统 3D 游戏的渲染高度。在《平面国》原著中，居民第一人称感知的是微薄发光的水平线带，上下高度过高会完全丧失“平面国一维线段感知”的文学代入感。
- **最佳实践**：视界光带高度收窄控制在 4px ~ 22px，重点通过横向明暗渐变以及等腰锐角的刺眼白炽光斑（Apex Luminescence）展现原著核心辨角机制。

### 5. 创伤震屏局部化与连震防抖
- **教训**：将震动 transform 施加于全屏外层容器（含 HUD、沙盘和按钮）会导致玩家强烈的眩晕与恶心感，且高频 Near-Miss 堆积创伤会造成无限死循环剧烈抖动。
- **最佳实践**：震动仅作用于第一人称视窗局部容器，且 Near-Miss 心跳震动必须加入冷却阻尼（0.5s 冷却，微量 0.06 脉冲）。

### 6. 进深轴测投影与第一人称直觉契合
- **教训**：若沙盘轴测前进投影朝向屏幕下方或右下，与第一人称按 W 向前推进的直觉产生严重矛盾。
- **最佳实践**：轴测矩阵必须将关卡主进深方向（+X 前往出口）严格投影为沿屏幕 Y 轴自下而上挺进。

### 7. 核心机制的仪式化引入（反生硬剧透）
- **教训**：一开局在角落放置不可点击的灰色终极技能按钮，会提前剧透叙事并给玩家带来失控感。
- **最佳实践**：开局保持低调的封印/冥想状态，在达成特定游戏目标（集齐 3 枚碎片）时，通过导师显圣等高光仪式唤醒技能。

### 8. 平面国一维视网膜槽的真实物理模拟（反假灯泡陷阱）
- **教训**：为了表现等腰尖角发光，而在 14px 微薄视网膜槽里强行绘制 26px 大红圆球光晕，会导致移动时像“头上顶着灯笼的虫子”，滑稽怪异且严重破坏文学代入感。
- **最佳实践**：回归 Beer-Lambert 指数衰减物理模型，等腰尖角仅体现为 6~10px 极窄的一道冷锋暗折痕，两翼急剧衰减隐入背景迷雾。

### 9. 升维玩法与石牢边界的绝对闭合性
- **教训**：如果在封闭石牢的出口侧开设豁口，会导致玩家在 2D 状态下直接走出去，使“必须向上升维才能脱逃”的核心玩法矛盾沦为笑话。
- **最佳实践**：四面高墙在数据与表现层必须 100% 严密闭合，出口设于墙外，唯有升维跨越方能通关。

### 10. 平面国建筑几何的纯粹性（拒绝 3D 巨石高墙立面）
- **教训**：为了强行表现“立体感”而给二维围墙画出厚重的 3D 棱台立面，完全违背了平面国的几何世界观，显得极其突兀笨重。
- **最佳实践**：石墙采用二维平整深墨高墙线框（线宽 3.2px 配合古典双道微金刻印），纯正还原维多利亚铜版画质感。

### 11. 视界对比度与神谕图标简洁统一
- **教训**：一味追求模糊衰减会导致第一人称灰突突一片不可读；给 3 个碎片画 3 种不同形状破坏了系统一致性。
- **最佳实践**：保持 26px 适中槽高与清晰的深墨/暗红冷锋对比；全场神谕碎片统一为端庄的【金菱星印】。

### 12. 视野感知表现（拒绝生硬单根竖线）
- **教训**：在上帝沙盘中若仅用单根前向竖线表达正方形视向，玩家感知为突兀生硬的“天线”或“刺刀”，毫无探索视野沉浸感。
- **最佳实践**：采用 60° 扇形微光探照视锥（Vision Cone），辅以微弱内发光与象牙米白多层学者方印，有机呈现绅士所见之范围。

### 13. 一维视网膜线纤薄化与 UI 独立防重叠
- **教训**：第一人称视界槽若超过 20px 容易被误以为是 2D 矩形窗口；出口徽标与文字重叠会严重降低信息辨识度。
- **最佳实践**：将第一人称感光槽收窄至 13px 极致纤薄微带，严格契合平面国“无厚度之一维光带”哲学；出口拱门与文字纵向独立分离 22px，并与沙盘顶端保持 68px 开阔距离。

### 14. 静态编译通过不等于运行时零报错（无头 CDP 真实页面体检铁律）
- **教训**：在 Canvas 循环渲染时若出现未捕获 ReferenceError（如将 `{ x: 5.2, y, z: 0 }` 笔误写成 `{ x, y: 5.2, z: 0 }`），`tsc` 在 DOM lib 宽松作用域下未拦住，导致第一帧抛出未捕获异常，使整个 `gameLoop` 卡死在首帧，呈现白板假象。
- **最佳实践**：验证流水线必须包含真实的 Headless Chrome CDP 控制台与页面截屏核验，确保无未捕获异常且首帧真实落图。

### 15. 多关卡流转的异构视窗适配与方法命名防御
- **教训**：从单关扩展至多关卡流转时，若不同关卡控制器对底层几何或射线接口命名有别名差异（如 `currentTriangle` 与 `getIsoscelesTriangle()`、`getFogRays` 与 `castRays`），跨关卡切换会抛出未捕获 TypeError 阻断 `gameLoop`。
- **最佳实践**：控制器必须提供完备的向后兼容别名；同时建立 CDP 跨关卡自动化切换（E2E）体检脚本，确保关卡往复切换时控制台零报错。

### 16. 原著形态严格忠实与一维前后物理光感反演
- **教训**：在直线国中若依然画 2D 正方形，破坏了原著设定的哲学浸润；若活动空间过小或开局即可侧移，玩家无法建立“单一直线无法逾越”的绝望体验，削弱了侧移顿悟的冲击力。
- **最佳实践**：主角在直线上呈现为学者线段，邻人为质点，国王为长线段；沙盘直线由左下至右上倾斜（契合 W 前进挺进感）；必须在 W 与 S 试探直线的两端绝路后方可解锁 A/D 向两侧侧移；第一人称按朝向精准反演 Beer-Lambert 前方长线段金芒与后方质点暗红针芒。

### 17. 沙盘标注去技术化与文学留白原则
- **教训**：在 UI 沙盘中堆砌“质点”、“长线段”、“暴躁后方”等底层几何分类与生硬术语，不仅显得啰嗦笨拙，更会严重出戏，破坏玩家在维多利亚手稿世界的文学代入感。
- **最佳实践**：纯净克制标注，仅保留核心角色专名（“暴躁邻人”、“线之国王”、“正方形绅士”），彻底删除几何分类术语与冗余方位赘词，文字与几何体保持 18px 舒适呼吸留白。
