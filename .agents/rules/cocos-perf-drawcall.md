# Cocos 渲染性能与 DrawCall 门禁规范

在交付游戏模块或构建验证前，必须审查以下性能指标：

1. **DrawCall 预算标准**：
   - 纯 UI 界面（背包、商城、弹窗）：**DrawCall <= 25**
   - 核心战斗/玩法主场景：**DrawCall <= 50**
   - 绝对不可逾越上限：**DrawCall <= 80**
2. **图集与碎图审查**：
   - 同一 UI 面板内的所有 Sprite 贴图必须包含在同一个 Auto Atlas（自动图集）中；
   - 严禁加载未经合图的零散 PNG 碎图。
3. **动静分层排版**：
   - 高频位移/缩放的动态元素（血条抖动、特效、跑马灯）必须单独置于动态层，禁止与大型静态背景共用同一父级容器。
4. **字体渲染开销控制**：
   - 频繁变动的数值（如伤害数字、金币跳字）优先使用 **BitmapFont（位图字）**，避免使用系统字导致频繁重新生成字符纹理。
