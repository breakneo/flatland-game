# Cocos Creator 3.x 像素风格研发硬性红线 (cocos-pixel-art-rules)

在进行像素风格游戏研发、资产导入与渲染设置时，必须 100% 遵守以下铁律：

## 1. 资产分层与包体红线
- **源文件绝对隔离**：`.aseprite` 与 `.piskel` 等源工程文件必须存放在项目根目录的 `assets_raw/` 目录；
- **禁止打包原始工程**：严禁将原始 `.aseprite` 文件拷贝进 `assets/` 目录，防止被 Cocos 引擎直接打包进主包或分包消耗体积；
- **仅发布运行时产物**：只有经过 CLI 导出的合批 PNG 图集和 JSON 数据方可存入 `assets/`。

## 2. 纹理采样与抗发虚红线
- **必须使用 Nearest 采样**：所有像素精灵、图集与 UI 图元的 Filter Mode 必须设为 `Nearest`（邻近过滤），严禁使用 `Bilinear` 或 `Trilinear` 插值；
- **禁用 Mipmap**：像素贴图必须关闭 Mipmap（设置为 `None`），防止相机缩放时模糊。

## 3. 相机与像素完美对齐红线 (Pixel Perfect)
- **强制正交投影**：主玩法 Camera 必须设置为 `Orthographic` 模式，禁止透视相机；
- **禁止非整数缩放**：设计分辨率缩放到视口必须保持整数倍比例（1x, 2x, 3x, 4x），严禁出现小数倍拉伸导致像素行/列变形；
- **渲染坐标整数化**：角色/物体最终赋给 Node 的渲染坐标必须通过 `Math.round()` 取整，杜绝亚像素移动导致的边缘摩尔纹与高频抖动。

## 4. 图集接缝防御红线
- **强制 1px 内边距**：使用 Aseprite CLI 或图集打包工具时，必须启用 `--inner-padding 1`，严禁无间距紧贴打包，彻底杜绝 GPU 采样溢色造成的贴图接缝黑边/杂色。
